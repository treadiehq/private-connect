# Documentation

Learn how to use Private Connect to access private services, integrate with AI tools, and collaborate with your team.

## Quick Start

### 1. Install Private Connect

```bash
curl -fsSL https://privateconnect.co/install.sh | bash
```

### 2. Start the agent

```bash
connect up
```

### 3. Expose or access services

```bash
connect 5432  # Expose
connect prod-db  # Access
```
